# REQ-007: Parse and validate verdict and justification

| Field | Value |
|---|---|
| Type | Functional |
| Priority | Must |
| Introduced in | v0.1 |
| Status | Draft |
| Use cases | UC-004 |

## Statement

The system shall accept a judge's reply only as a supported verdict (PASS or FAIL) with a non-empty justification.

## Rationale

Free-form judge output cannot be scored reliably; a strict contract makes every verdict machine-checkable.
