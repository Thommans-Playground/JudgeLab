# REQ-003: Configure target and judge independently

| Field | Value |
|---|---|
| Type | Functional |
| Priority | Must |
| Introduced in | v0.1 |
| Status | Draft |
| Use cases | UC-001, UC-004, UC-006 |

## Statement

The system shall let the target model and the judge model be configured independently, so that either can be changed without changing the other or any code.

## Rationale

Comparing models, and avoiding a model judging itself, both need the two roles to vary independently.
