# REQ-002: Validate records, including required fields and unique IDs

| Field | Value |
|---|---|
| Type | Functional |
| Priority | Must |
| Introduced in | v0.1 |
| Status | Draft |
| Use cases | UC-002 |

## Statement

The system shall validate a benchmark before running it, rejecting missing or empty fields, unknown fields and duplicate case ids, and shall report every problem found in one go.

## Rationale

A malformed benchmark silently produces meaningless results; reporting all problems at once saves fix-and-retry cycles.
