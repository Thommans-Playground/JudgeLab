# REQ-001: Load benchmark cases with question and expected answer

| Field | Value |
|---|---|
| Type | Functional |
| Priority | Must |
| Introduced in | v0.1 |
| Status | Draft |
| Use cases | UC-002 |

## Statement

The system shall load a benchmark (an id, a name and a list of test cases, each with an id, a question and an expected answer) from a JSON file.

## Rationale

Benchmarks are the input to every evaluation; a plain, versionable file format keeps them reviewable and reproducible.
