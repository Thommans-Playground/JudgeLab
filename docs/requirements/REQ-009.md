# REQ-009: Calculate transparent aggregate metrics and error coverage

| Field | Value |
|---|---|
| Type | Functional |
| Priority | Must |
| Introduced in | v0.1 |
| Status | Draft |
| Use cases | UC-005 |

## Statement

The system shall report, for each run, the number of passed, failed and errored cases, a pass rate of passed / (passed + failed), and the coverage of cases that reached a verdict.

## Rationale

A pass rate is only meaningful together with how many cases it is based on; errors must be visible, not absorbed into the rate.
