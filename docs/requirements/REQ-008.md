# REQ-008: Distinguish execution/parse errors from negative verdicts

| Field | Value |
|---|---|
| Type | Functional |
| Priority | Must |
| Introduced in | v0.1 |
| Status | Draft |
| Use cases | UC-004, UC-006 |

## Statement

The system shall record execution failures, unreadable judge replies and truncated answers as ERROR, never as a failed answer (FAIL).

## Rationale

Counting an outage or a broken reply as a wrong answer would understate the model's quality and hide the real problem.
