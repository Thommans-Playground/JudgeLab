# REQ-012: Support deterministic tests with fake connectors

| Field | Value |
|---|---|
| Type | Non-functional |
| Priority | Must |
| Introduced in | v0.1 |
| Status | Draft |
| Use cases | UC-001 |

## Statement

Every behaviour of the system shall be testable without network access, API keys or cost, by using fake connectors that behave like real ones.

## Rationale

Fast, free and deterministic tests are what make frequent change safe; real model calls are slow, costly and non-deterministic.
