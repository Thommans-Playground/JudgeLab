# REQ-011: Expose end-to-end execution through a CLI

| Field | Value |
|---|---|
| Type | Functional |
| Priority | Must |
| Introduced in | v0.1 |
| Status | Draft |
| Use cases | UC-006 |

## Statement

The system shall run a complete evaluation from a single command that reads a configuration file, shows progress and a summary, and writes the report.

## Rationale

A single repeatable command is the basis for both manual runs and, later, continuous evaluation in CI.
