# REQ-004: Support provider, model ID, optional base URL, and API-key environment reference

| Field | Value |
|---|---|
| Type | Functional |
| Priority | Must |
| Introduced in | v0.1 |
| Status | Draft |
| Use cases | UC-001 |

## Statement

Each model connection shall be configured with a provider, a model id, an optional base URL, and the name of the environment variable that holds its API key, and invalid configurations shall be rejected with clear errors.

## Rationale

Configuration is the only thing that should change between providers and environments; validating it early stops runs that would fail later.
