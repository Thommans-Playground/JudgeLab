# REQ-005: Obtain actual answers from the target model

| Field | Value |
|---|---|
| Type | Functional |
| Priority | Must |
| Introduced in | v0.1 |
| Status | Draft |
| Use cases | UC-001, UC-003, UC-006 |

## Statement

The system shall send each test case's question to the target model and capture its answer, or its refusal, together with the call's metadata (served model, finish reason, tokens, request id, latency).

## Rationale

The target's actual answer is the evidence being evaluated; the metadata makes each result traceable and reproducible.
