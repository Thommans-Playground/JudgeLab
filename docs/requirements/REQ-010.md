# REQ-010: Persist per-case evidence and execution metadata as JSON

| Field | Value |
|---|---|
| Type | Functional |
| Priority | Must |
| Introduced in | v0.1 |
| Status | Draft |
| Use cases | UC-005 |

## Statement

The system shall write each run as a JSON report holding every case's evidence (question, expected and actual answer, verdict, justification, model calls, errors) and the run's metadata.

## Rationale

Results must be reviewable by a human and comparable across runs long after the process has ended.
