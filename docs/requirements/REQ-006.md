# REQ-006: Judge actual answers against question, reference, and rubric

| Field | Value |
|---|---|
| Type | Functional |
| Priority | Must |
| Introduced in | v0.1 |
| Status | Draft |
| Use cases | UC-004, UC-006 |

## Statement

The system shall have a judge model evaluate each actual answer against its question, its expected answer and a rubric, and record the judge's identity with the result.

## Rationale

An LLM judge can assess answers that are correct in meaning but not in exact wording; recording its identity keeps verdicts auditable.
