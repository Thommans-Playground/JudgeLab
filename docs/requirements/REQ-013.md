# REQ-013: Keep secrets out of logs, errors, and reports

| Field | Value |
|---|---|
| Type | Non-functional |
| Priority | Must |
| Introduced in | v0.1 |
| Status | Draft |
| Use cases | UC-001, UC-005, UC-006 |

## Statement

API keys shall never appear in configuration files, logs, error messages, reprs or reports.

## Rationale

A leaked key is a security incident; JudgeLab's outputs are designed to be shared, so they must never carry secrets.
